Investigacion en desarrollo | Universidad de Colima

Vision artificial para dar una via de comunicacion cuando el habla no alcanza.

Este proyecto desarrolla un prototipo de reconocimiento de expresiones faciales en tiempo real para apoyar la Comunicacion Aumentativa y Alternativa en personas con paralisis cerebral. La idea es convertir senales del rostro en mensajes comprensibles para cuidadores y terapeutas.

Ver funcionamiento Ver resultados
Pipeline en tiempo real 34 ms
EntradaWebcam 30 FPS
Analisis478 landmarks
SalidaPictograma + voz
478 puntos faciales detectados con MediaPipe Face Mesh
68 metricas geometricas para describir la expresion
3 estados iniciales: alegria, neutral y dolor
< 500 ms meta de latencia para uso en hardware comun

El problema

Comunicar dolor o bienestar puede depender de senales muy sutiles.

La paralisis cerebral puede afectar el movimiento, la postura y la comunicacion verbal. En algunos casos, una persona puede tener algo urgente que expresar, pero no contar con el habla como canal confiable.

El proyecto explora una alternativa no invasiva: usar una camara comun para observar expresiones faciales y traducirlas en apoyos visibles o audibles. No busca diagnosticar ni reemplazar al especialista; busca aportar una senal adicional para interpretar mejor a la persona.

Pregunta de investigacion

¿Es viable desarrollar un sistema FER operativo en tiempo real, ejecutable en hardware de consumo, como base para una herramienta CAA en paralisis cerebral?

Captura accesible

El sistema esta pensado para funcionar con una webcam y una computadora comun, sin depender de equipo clinico costoso.

Rasgos interpretables

Las distancias, aperturas y proporciones del rostro permiten explicar que cambios alimentan al modelo.

Salida util

La respuesta se traduce a tarjetas visuales y voz para que el cuidador tenga una senal clara durante la interaccion.

Metodologia

Una ruta modular para probar viabilidad tecnica.

01

Datos y aumentacion

Se parte de datasets publicos como RAF-DB y CK+, con aumentacion clasica para las clases dolor, alegria y neutral.

02

Extraccion facial

MediaPipe Face Mesh detecta landmarks faciales y el sistema genera un vector compacto de caracteristicas geometricas.

03

Modelado

Se comparan clasificadores ligeros como SVM y MLP, ademas de una CNN ligera como referencia experimental.

04

Interfaz

El modelo se integra a una GUI que comunica el estado detectado mediante color, texto, pictograma y voz.

Evidencia del prototipo

Resultados iniciales y lectura honesta.

Los resultados muestran una base tecnica prometedora, pero tambien dejan claro el siguiente reto: validar y recalibrar el sistema con datos reales de personas con paralisis cerebral. La prioridad no es vender una precision perfecta, sino demostrar una arquitectura viable y mejorable.

Modelo Accuracy F1 macro AUC ROC Lectura
SVM 0.6885 0.6762 0.8652 Mejor equilibrio general en la evaluacion rapida.
MLP 0.6823 0.6724 0.8592 Inferencia muy rapida, buena candidata para tiempo real.
SmallEmotionCNN 0.5926 0.6011 0.8826 Buen AUC, pero requiere mas ajuste para clasificacion final.

Registro multimodal

GSR como contexto, no como diagnostico.

flowchart TB
  A[Sesion de terapia] --> B[Camara]
  A --> C[Sensor GSR]
  B --> D[Capturas y expresiones]
  C --> E[Actividad fisiologica]
  D --> F[Revision posterior]
  E --> F
  F --> G[Momentos relevantes para analizar]

El registro GSR/EDA puede ayudar a ubicar momentos de activacion fisiologica durante una sesion. Su papel es contextual: se revisa junto con las capturas, los eventos de terapia y la observacion del cuidador.

Esta linea abre la puerta a un sistema multimodal, donde rostro, fisiologia y contexto terapeutico se analicen juntos con mayor responsabilidad.
