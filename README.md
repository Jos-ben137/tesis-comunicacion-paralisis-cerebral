# Tesis: comunicacion en personas con paralisis cerebral

Progreso en tesis sobre Comunicación en Personas con Parálisis Cerebral.

Repositorio de avance de tesis sobre comunicacion en personas con paralisis cerebral.

## Pagina web

La pagina principal esta en `index.html` y usa `styles.css`. Esta preparada para publicarse con GitHub Pages desde la raiz del repositorio.

Incluye una copia del poster en `assets/poster-vision-artificial-paralisis-cerebral.pdf` para que la pagina funcione como complemento durante la presentacion.

Tambien incluye el documento formal de avance al 80% en `assets/proyecto-investigacion-avance-80-integrado.pdf`, usado como base conceptual de la pagina.

Para activarla:

1. En GitHub, entra a **Settings > Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/root`.
4. Guarda los cambios y espera la URL publica de GitHub Pages.

La pagina incluye diagramas del flujo del prototipo CAA, metodologia, registro GSR y resultados visuales generados en `files/resultados_rapidos/` y `files/resultados_cnn_train_test/`.
